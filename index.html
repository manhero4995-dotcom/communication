LECTURE 1 — Chapter 1: Introduction to Digital Communications

Big idea (one sentence)

A digital communication system converts any source (analog or digital) into bits, protects those bits against noise, transmits them as waveforms over a channel, and reverses the whole process at the receiver.

1. Definition

A digital communication system is a communication system that uses a digital sequence (bits: 1s and 0s) as the interface between:

  • the source and the channel input, and
  • the channel output and the final destination.

So the common language of the whole system is binary.

2. General digital communication system

Transmitter side (left → right):

Block Simple job Key words to write in the exam
Information source & input transducer Produces the message and converts it to an electrical signal Analog source: audio, video. Digital source: teletype. Output is converted to 1s and 0s.
Source encoder Converts the source output into as few bits as possible Source encoding = data compression. Removes redundancy. Output = information sequence.
Channel encoder Adds controlled redundancy so the receiver can correct/ detect errors Maps k information bits → n-bit codeword. Redundancy = n/k. Code rate = k/n.
Digital modulator Maps the binary sequence into signal waveforms that can travel on the channel Binary sequence → electric signal / waveform.
Channel The physical medium carrying the signal Wired: copper (coaxial, twisted pair), optical fiber. Wireless: atmosphere (TV, radio, mobile).

Receiver side (right → left): the exact reverse:

Digital demodulator → Channel decoder → Source decoder → Output transducer.

The channel is the part that adds noise and interference; that is why channel coding exists.

3. Why digital communication is now the standard

Benefit Meaning in simple words
Cheap, reliable, miniaturized hardware Digital circuits are easy and cheap to build.
Standardized binary interface Source and channel can be designed independently.
Simplifies networking Everything speaks the same 1/0 language.
Shannon's source/channel separation theorem If a source can be sent over a channel at all, it can be sent through a binary interface.
Better immunity to noise and distortion Works well as long as noise/distortion are within limits.
Regenerative repeaters Regenerate clean bits, so noise does not accumulate along the path.
Coding Gives very low error rates, high fidelity, and privacy.
Efficient SNR ↔ bandwidth exchange Digital can trade signal-to-noise ratio for bandwidth better than analog.
Easy multiplexing Several digital signals are easy to combine.
Cheap storage Digital data is easy and inexpensive to store.
Moore's law Cost halves every 2–3 years while performance/capacity doubles.

4. Disadvantages of digital communication

  1. TDM is not compatible with FDM (Time Division Multiplexing vs Frequency Division Multiplexing).
  2. A digital system requires large bandwidth (BW).

Exam trap: "large bandwidth" is a disadvantage, not an advantage.

5. Standardized interfaces and layering

Large networks (PSTN, the Internet) are very complex, so they need simple architectural principles:

Standardized interface

An interface that lets the user/equipment on one side ignore all details of the other side, except for certain specified interface characteristics.

Example: the binary interface lets source coding/decoding be done independently of channel coding/decoding.

Layering

Breaking communication functions into a string of separate layers.

  • Each layer has an input module at the input end and a peer output module at the other end.
  • Input module at layer i: processes information received from layer i+1, then sends it to layer i−1.
  • Peer output module at layer i: works in the opposite direction — receives from layer i−1, sends to layer i.

Must memorize for Lecture 1

  • Definition of a digital communication system (digital sequence as interface).
  • The 5 transmitter blocks in order and the 5 receiver-side blocks in reverse order.
  • Source encoder = compression; channel encoder = controlled redundancy.
  • Code rate = k/n, redundancy = n/k.
  • At least 5 advantages + the 2 disadvantages.
  • Definitions of standardized interface and layering.

Common exam traps — Lecture 1

  • Do not say the channel encoder compresses data. It adds redundancy.
  • Do not say source encoding adds redundancy. It removes redundancy.
  • TDM vs FDM incompatibility is a disadvantage.
  • The binary interface is what allows source coding and channel coding to be independent.

LECTURE 2 — Chapter 1 (cont'd): Digital Communication Channels + Line Coding

Big idea (one sentence)

The channel is the given, uncontrolled part of the system, and noise limits how many bits we can reliably distinguish; line coding is how we choose voltage/current waveforms to represent those bits on the wire.

1. What is a channel?

  • The channel is the part of the communication system between source and destination that is given and not under the control of the designer.
  • To a source-code designer, the channel may be a digital channel with binary input and output.
  • Amplifiers, antennas, lasers, etc. that couple the waveform to the physical medium may be considered part of the channel or part of the channel encoder.

2. Modulation terminology (very examinable)

  • Channel encoding/decoding, when the channel is the physical medium (with or without amplifiers, antennas, lasers), is usually called (digital) modulation and demodulation.
  • The challenging part is converting binary data → baseband waveforms.
  • Converting baseband → passband and back is called frequency conversion.

Memory hook: modulation = bits to waveform; frequency conversion = baseband to passband.

3. Channel representation

A channel is described by:

  1. its possible inputs,
  2. its possible outputs, and
  3. a description of how the input affects the output — usually probabilistic.

If the channel were simply a linear time-invariant (LTI) system (e.g., a filter), it could be completely characterized by its impulse response or frequency response.

Why noise matters

With no noise, one could represent a single voltage level by its infinite binary expansion and transmit an infinite number of bits using one real number. In practice this is impossible: noise limits the number of bits that can be reliably distinguished.

4. Channel models

AWGN channel (the most common model)

An Additive White Gaussian Noise channel adds an independent white Gaussian noise waveform to the input:

Y(t) = X(t) + Z(t)
  • X(t) = input waveform
  • Z(t) = additive white Gaussian noise
  • Y(t) = output waveform

Linear Gaussian channel

The input first passes through a linear filter with impulse response h(t), then independent white Gaussian noise is added:

Y(t) = X(t) * h(t) + Z(t)

where * means convolution.

  • Good model for wireline communication and line-of-sight (LOS) wireless.
  • Poor model for non-line-of-sight (NLOS) mobile communication, because mobility and reflections make the paths change with time.

Mobile channel model

Replace the fixed filter h(t) by a randomly time-varying linear filter H(u,t) that represents multiple paths changing in time:

Y(t) = ∫ X(t − u) H(u,t) du + Z(t)

5. Line coding

Definition

  • A line code is a code chosen for use within a communication system for transmitting a digital signal down a transmission line.
  • The waveform pattern of voltage or current used to represent the 1s and 0s of a digital signal on a transmission link is called line encoding.
  • Line codes are commonly used in computer communication networks over short distances.

The 9 line codes in the lecture

Code Rule (memorize this table)
NRZ-L Non-return-to-zero level. 1 → high level, 0 → low level. Standard positive logic used in digital circuits.
NRZ-M Non-return-to-zero mark. 1 → forces a transition at the start of the bit; 0 → does nothing.
NRZ-S Non-return-to-zero space. 1 → does nothing; 0 → forces a transition at the start of the bit.
RZ Return-to-zero. 1 → high for half the bit period, then returns to zero; 0 → stays at zero.
Biphase-L Manchester. 1 → negative transition in the middle of the bit; 0 → positive transition in the middle. Two consecutive same bits force a transition at the bit boundary.
Biphase-M There is always a transition at the beginning of a bit. 1 → also forces a transition in the middle; 0 → does nothing in the middle.
Biphase-S There is always a transition at the beginning of a bit. 1 → does nothing in the middle; 0 → forces a transition in the middle.
Differential Manchester There is always a transition in the middle of a bit. 1 → does nothing at the start; 0 → forces a transition at the beginning.
Bipolar Positive and negative pulses alternate. 1 → a positive or negative pulse for half the bit period; 0 → does nothing (zero). Three levels: +, 0, −.

Worked drawing — sequence 0011010110

Assumptions used for the drawing (state them in the exam): - NRZ-M and NRZ-S start from the low level. - Biphase-M and Biphase-S start from the low level before the first bit (so the mandatory start-of-bit transition gives a high first half). - Differential Manchester starts low. - Bipolar/AMI gives the first 1 a positive pulse. - Any consistent initial state is acceptable if you apply the same rule throughout.

How to draw any line code quickly

  1. Draw the bit cells and write the bits above them.
  2. Decide the starting level.
  3. For each bit, ask: is there a transition at the start? in the middle?
  4. Draw only the levels; then join with vertical lines at transitions.
  5. For RZ and Bipolar, remember the pulse lasts only half a bit.

Must memorize for Lecture 2

  • Channel definition and the three parts of its representation.
  • Y = X + Z (AWGN) and Y = X*h + Z (linear Gaussian).
  • Linear Gaussian is good for wireline/LOS, bad for NLOS mobile.
  • Line coding definition.
  • The 9 line-code rules — especially NRZ-M vs NRZ-S and the three biphase codes.

Common exam traps — Lecture 2

  • NRZ-M vs NRZ-S: M = mark = 1 causes the transition; S = space = 0 causes the transition.
  • Biphase-L (Manchester): 1 = high→low (negative middle transition), 0 = low→high.
  • Biphase-M vs Biphase-S: both have a guaranteed transition at the start; M reacts to 1 in the middle, S reacts to 0 in the middle.
  • Differential Manchester: the guaranteed transition is in the middle; 0 adds a transition at the start.
  • Bipolar is a three-level code, not two-level.
  • Don't confuse "line coding" (waveform choice) with "channel coding" (error protection).

LECTURE 3 — Chapter 2: Digital Modulation

Big idea (one sentence)

Digital modulation puts the bits onto a carrier by changing one of its three parameters — amplitude (ASK), frequency (FSK), or phase (PSK); the receiver decides which symbol was sent by measuring that parameter.

1. Passband transmission

  • The incoming data stream is modulated onto a carrier with a fixed frequency and then transmitted over a band-pass channel — this is passband transmission.
  • The three basic signaling schemes are: 1. Amplitude Shift Keying (ASK) 2. Frequency Shift Keying (FSK) 3. Phase Shift Keying (PSK)

The general carrier is:

v(t) = V sin(2π f t + θ)
  • Change V → ASK
  • Change f → FSK
  • Change θ → PSK
  • Combine amplitude and phase → QAM

2. M-ary encoding

  • M = number of possible conditions, levels, or combinations for a given number of binary variables.
  • Example: a system with 4 possible voltage levels/frequencies/phases is M-ary with M = 4.
  • The number of bits needed to produce M conditions:
N = log2 M          (bits per symbol)
M = 2^N

Examples: M = 2 → N = 1; M = 4 → N = 2; M = 8 → N = 3.

3. Baud and minimum bandwidth

Quantity Formula / meaning
Baud Rate of change of the signal after encoding and modulation. Also called modulation rate or symbol rate.
Baud Baud = 1 / Ts, where Ts = time of one signaling element (seconds)
Binary Nyquist fb = 2B, where B is the ideal Nyquist bandwidth → B = fb/2 for ideal binary baseband signaling.
Multilevel Nyquist fb = B log2 M → B = fb/log2 M
Minimum bandwidth B = fb / log2 M = fb / N
Baud Baud = fb / N

Important distinction: B = fb/2 is the ideal Nyquist baseband bandwidth (the theoretical minimum). For the passband schemes in this course, the minimum transmission bandwidth is Bmin = fb for binary ASK and BPSK, and Bmin = fb/2 for QPSK. FSK is 2(Δf + fb). Use the formula the question asks for.

Simple version: - N = bits carried by one symbol. - Baud counts symbols per second. - fb counts bits per second. - Therefore fb = Baud × N, so Baud = fb/N.

Example from the lecture: a telephone circuit with B = 2700 Hz can carry fb = 2B = 5400 bps with binary signaling.

4. Signal constellation diagram

A constellation diagram represents a digitally modulated signal as a two-dimensional X–Y scatter diagram in the complex plane, at the symbol sampling instants.

  • Each point = one possible symbol.
  • The axes are usually the in-phase (I) and quadrature (Q) components.
  • The farther apart the points, the easier the receiver can distinguish them in noise.

5. Amplitude Shift Keying (ASK)

Principle

  • The simplest digital modulation technique.
  • The binary information signal directly modulates the amplitude of an analog carrier.
  • Only two output amplitudes are possible (binary ASK).
  • Also called Digital Amplitude Modulation (DAM).

Mathematics

V_ASK(t) = {1 + Vm(t)} [A/2 cos(ωc t)]
  • Vm(t) = digital modulating signal: +1 V for logic 1, −1 V for logic 0.
  • A/2 = unmodulated carrier amplitude.
  • ωc = 2πfc = carrier radian frequency.

For logic 1: V_ASK = A cos(ωc t). For logic 0: V_ASK = 0.

Therefore the carrier is either ON or OFF → ASK is also called On–Off Keying (OOK).

Transmitter

  • Binary sequence → product modulator.
  • The product modulator amplitude-modulates the carrier.
  • Bit 1 → passes the carrier.
  • Bit 0 → blocks the carrier.

Baud

For binary ASK, one bit per symbol, so:

Baud = fb

Probability of error (matched-filter detection)

Pe = ½ erfc( √(Eb / 4N0) )

where Eb = energy per bit, N0/2 = two-sided noise power spectral density.

Bandwidth

For binary ASK: Bmin = Baud = fb.

6. Frequency Shift Keying (FSK)

Principle

  • The frequency of the carrier changes according to the digital input.
  • Binary 1 → mark frequency (high frequency).
  • Binary 0 → space frequency (low frequency).
  • Also called Binary FSK (BFSK).

Mathematics

V_FSK(t) = Vc cos[ 2π (fc + Vm(t) Δf) t ]
  • Vc = peak carrier amplitude.
  • fc = center frequency.
  • Δf = peak frequency deviation (shift).
  • Vm(t) = +1 for logic 1, −1 for logic 0.

For logic 1: frequency = fc + Δf (mark). For logic 0: frequency = fc − Δf (space).

Transmitter

  • The binary input drives a Voltage-Controlled Oscillator (VCO).
  • fc is chosen halfway between the mark and space frequencies.
  • Logic 1 shifts the VCO to the mark frequency.
  • Logic 0 shifts the VCO to the space frequency.
  • Peak deviation: Δf = Vm(t) Kl, where Kl = deviation sensitivity in Hz/V.

Receivers

Noncoherent FSK receiver Coherent FSK receiver
Input → power splitter → two BPFs (one for mark, one for space) → two envelope detectors → comparator. Input is multiplied by a recovered carrier with the same frequency and phase as the transmitter reference.
Each BPF passes only its frequency. Requires a local reference coherent with both mark and space.
Envelope detectors measure the total power in each passband. The mark and space frequencies are generally not continuous, so it is impractical to reproduce a local reference coherent with both.
Comparator selects the larger power → decides the bit. Therefore coherent FSK detection is seldom used.

Probability of error

Noncoherent FSK:

Pe = ½ erfc( √(Eb / 2N0) )

Coherent FSK:

Pe = ½ erfc( √(Eb / N0) )

Bandwidth

Δf = |fs − fm| / 2
Bmin = 2(Δf + fb)

Baud

For binary FSK: Baud = fb.

7. Phase Shift Keying (PSK)

Principle

  • The phase of the carrier changes according to the input.
  • The amplitude stays constant.
  • Widely used in wireless LANs, biometrics, contactless operations, RFID, and Bluetooth.

Types

  1. Binary PSK (BPSK) — 2 phases.
  2. Quadrature PSK (QPSK) — 4 phases.
  3. Differential PSK (DPSK) — phase changes relative to the previous value.

8. Binary Phase Shift Keying (BPSK)

Principle

  • Also called 2-phase PSK, Phase Reversal Keying, or bi-phase modulation.
  • The sine-wave carrier takes two phase reversals: 0° and 180°.
  • N = 1, M = 2.
  • One phase represents logic 1; the other represents logic 0.
  • BPSK is a form of square-wave modulation of a continuous wave (CW) signal.

Waveform

  • Logic 1 → +sin(ωc t) (phase 0°).
  • Logic 0 → −sin(ωc t) (phase 180°).
  • Each time the input logic changes, the output phase changes by 180°.

Transmitter

  • The balanced modulator acts as a phase-reversing switch.
  • Depending on the logic condition, the carrier reaches the output in phase or 180° out of phase with the reference carrier.
  • Balanced ring modulator has two inputs: the carrier (in phase with the reference oscillator) and the binary data.
  • For proper operation, the digital input voltage must be much greater than the peak carrier voltage, so the digital input controls the on/off state of diodes D1–D4.
  • Logic 1 (positive voltage): D1 and D2 forward-biased (ON), D3 and D4 reverse-biased (OFF); carrier across T2 is in phase with the carrier across T1.
  • Logic 0: the opposite diodes conduct; the carrier is inverted.

Truth table

Binary input Phase Output
1 0° +sin(ωc t)
0 180° −sin(ωc t)

Receiver

  • Input may be +sin(ωc t) or −sin(ωc t).
  • A coherent carrier recovery circuit regenerates a carrier with the same frequency and phase as the transmitter carrier.
  • The balanced modulator acts as a product detector: output = product of the BPSK signal and the recovered carrier.
  • The low-pass filter (LPF) removes the double-frequency term and recovers the binary data.

For input +sin(ωc t) (logic 1):

(sin ωc t)(sin ωc t) = sin² ωc t
= 0.5(1 − cos 2ωc t)
= 0.5 − 0.5 cos 2ωc t

The cos 2ωc t term is filtered out → output +0.5 V → logic 1.

For input −sin(ωc t) (logic 0):

(−sin ωc t)(sin ωc t) = −sin² ωc t
= −0.5(1 − cos 2ωc t)
= −0.5 + 0.5 cos 2ωc t

The cos 2ωc t term is filtered out → output −0.5 V → logic 0.

Bandwidth of BPSK

The output is proportional to:

[sin(2πfa t)] × [sin(2πfc t)]
= 0.5 cos[2π(fc − fa)t] − 0.5 cos[2π(fc + fa)t]

where fa = maximum fundamental frequency of the binary input, fc = carrier frequency.

  • Minimum double-sided Nyquist bandwidth: B = 2fa.
  • Since fa = fb/2: B = fb.
  • The BPSK signaling element time ts equals one bit time tb, so Baud = fb.

Probability of error (coherent BPSK)

Pe = ½ erfc( √(Eb / N0) )

This is the same expression as coherent FSK in this course.

12. Common exam traps — Lecture 3

  • ASK Pe has 4N0 under the root; noncoherent FSK has 2N0; coherent FSK/BPSK has N0. Mixing these up is the most common mistake.
  • BPSK: baud = bit rate. QPSK: baud = half the bit rate.
  • FSK bandwidth is 2(Δf + fb), not 2Δf.
  • Mark = 1, space = 0.
  • In QPSK, the bit-pair order matters; the sheet uses Q I in its truth table. State your convention.
  • The BPSK carrier is suppressed; the spectrum has two sidebands at fc ± fa.
  • ASK is not the same as ordinary AM: it has only two output amplitudes.

LECTURE 4 — Chapter 2 (cont'd): Quadrature Phase Shift Keying (QPSK)

Big idea (one sentence)

QPSK is two BPSK systems working together: it splits the bit stream into I and Q channels, puts one bit on each carrier (90° apart), and combines them — so each symbol carries 2 bits in the same bandwidth that BPSK needs for 1 bit.

1. Definition

QPSK is an M-ary encoding scheme with:

N = 2,   M = 4
  • A QPSK modulator accepts a binary (base-2) signal and produces four different input combinations: 00, 01, 10, 11
  • The binary input data are combined into groups of two bits, called dibits.
  • Each dibit code generates one of the four possible output phases: +45°, +135°, −45°, −135°

2. Features of QPSK

  • QPSK is a variation of BPSK.
  • It is a DSB-SC (double-sideband suppressed-carrier) modulation scheme.
  • It sends two bits of digital information at a time (per symbol).
  • Instead of converting the bits into a single serial stream, it converts them into bit-pairs (dibits).
  • This decreases the data bit rate to half in each channel, which allows space for other users.

The lecture slide says "called as digits"; the correct term is dibits.

3. QPSK transmitter

Step-by-step operation

  1. Two bits (a dibit) are clocked into the bit splitter.
  2. After both bits have been serially input, they are simultaneously output in parallel: - one bit to the I (in-phase) channel, - one bit to the Q (quadrature) channel.
  3. Each channel has a bit rate of: fb / 2
  4. The I channel multiplies its bit stream by sin(ωc t) in a balanced modulator.
  5. The Q channel multiplies its bit stream by cos(ωc t) (90° shifted) in another balanced modulator.
  6. The two outputs are added in a linear summer and band-pass filtered.

−sin(ωc t) + cos(ωc t)
−sin(ωc t) − cos(ωc t)

Each phasor is one of the four QPSK symbols.

4. Bandwidth considerations of QPSK

This is the part students lose marks on, so follow the logic slowly.

Step 1 — Bit rate in each channel

The input data rate is fb. The bit splitter divides it into two channels:

Bit rate in I channel = fb / 2
Bit rate in Q channel = fb / 2

Step 2 — Highest fundamental frequency

The highest fundamental frequency of the modulating waveform in each channel is:

fa = fb / 4

This is the "one-half of fb/2 = fb/4" statement in the lecture.

Step 3 — Output of each balanced modulator

Output = (sin ωa t)(sin ωc t)

with:

ωa t = 2π(fb/4)t      (modulating signal)
ωc t = 2πfc t         (carrier)

Using the product-to-sum identity:

Output = ½ cos[2π(fc − fb/4)t] − ½ cos[2π(fc + fb/4)t]

So the sidebands are at:

fc − fb/4    and    fc + fb/4

Step 4 — Minimum bandwidth

fN = (fc + fb/4) − (fc − fb/4)
   = 2(fb/4)
   = fb/2

The carrier frequency fc cancels out, so the bandwidth does not depend on the carrier frequency.

5. QPSK receiver

Operation

  1. The recovered carrier must be frequency and phase coherent with the transmit reference carrier.
  2. A 90° phase shifter produces the quadrature carrier.
  3. Two product detectors multiply the incoming signal by sin(ωc t) and cos(ωc t).
  4. Two LPFs remove the double-frequency terms and produce the I and Q baseband signals.
  5. The bit combining circuit converts the parallel I and Q data channels into a single binary output data stream.
  6. Clock recovery keeps the receiver synchronized.

Worked receiver example (from the lecture)

Let the incoming QPSK signal be:

−sin(ωc t) + cos(ωc t)

This is the symbol with Q = 1, I = 0 (phase +135°).

I-channel product detector (multiply by sin ωc t):

I = (−sin ωc t + cos ωc t)(sin ωc t)
  = −sin² ωc t + (cos ωc t)(sin ωc t)
  = −½(1 − cos 2ωc t) + ½sin(2ωc t)
  = −½ + ½cos 2ωc t + ½sin 2ωc t

After the LPF, the 2ωc t terms are removed:

I = −½ V  →  logic 0

Q-channel product detector (multiply by cos ωc t):

Q = (−sin ωc t + cos ωc t)(cos ωc t)
  = −(sin ωc t)(cos ωc t) + cos² ωc t
  = −½sin(2ωc t) + ½(1 + cos 2ωc t)
  = ½ + ½cos 2ωc t − ½sin 2ωc t

After the LPF:

Q = +½ V  →  logic 1

So the recovered bits are Q = 1, I = 0, matching the transmitted symbol.

SHEET 1 — Chapter 1: Introduction + Channels + Line Coding

Q1. What is meant by a digital communication system?

A digital communication system is a communication system that uses a digital sequence as the interface between the source and the channel input, and similarly between the channel output and the final destination.

In other words, the message is converted into bits (1s and 0s), transmitted as digital waveforms, and converted back to the original form at the receiver.

Q2. By the aid of neat sketches, explain briefly the main components of a general digital communication system.

Transmitter side

  1. Information source and input transducer - The source may be analog (audio, video) or digital (e.g., teletype). - Its output is converted into a digital signal consisting of 1s and 0s.

  2. Source encoder - Converts the source output into a sequence of binary digits as efficiently as possible. - Also called data compression. - It uses as few bits as possible and produces little or no redundancy. - Its output is called the information sequence.

  3. Channel encoder - Introduces controlled redundancy into the binary information sequence. - The redundancy allows the receiver to overcome the effects of noise and interference. - It maps k information bits into a unique n-bit codeword. - Redundancy = n/k; code rate = k/n.

  4. Digital modulator - Converts the binary sequence into electric signal waveforms that can be transmitted over the channel. - It maps binary sequences into signal waveforms.

  5. Channel - The physical medium used to transmit signals from transmitter to receiver. - Wired: copper cables (coaxial, twisted pair) or optical fiber. - Wireless: atmosphere (TV, radio, mobile).

Receiver side

The receiver performs the reverse operations:

Digital demodulator → Channel decoder → Source decoder → Output transducer.

  • The demodulator converts the received waveform back to bits.
  • The channel decoder uses the redundancy to detect/correct errors.
  • The source decoder decompresses the information.
  • The output transducer converts the electrical signal back to the desired output form.

Q3. Determine the main advantages and disadvantages of digital communication systems.

Advantages

  1. Digital hardware is cheap, reliable, and miniaturized.
  2. Standardized binary interfaces simplify implementation and understanding.
  3. They simplify networking.
  4. Digital communication can withstand noise and distortion much better, as long as they are within limits.
  5. Regenerative repeaters prevent the accumulation of noise along the path.
  6. Digital signals can be coded to give very low error rates, high fidelity, and privacy.
  7. Digital communication is more efficient in realizing the exchange of SNR for bandwidth.
  8. It is easier and more efficient to multiplex several digital signals.
  9. Digital signal storage is inexpensive and relatively easy.
  10. The cost of digital hardware halves every 2–3 years, while performance or capacity doubles over the same period.

Disadvantages

  1. TDM digital transmission is not compatible with FDM.
  2. A digital system requires large bandwidth (BW).

Q4. Explain what is meant by layers and interfaces in a digital communication system.

Standardized interface

A standardized interface allows the user or equipment on one side of the interface to ignore all details about the other side, except for certain specified interface characteristics.

Example: the binary interface allows source coding/decoding to be done independently of channel coding/decoding.

Layering

Layering is the idea of breaking up communication functions into a string of separate layers.

  • Each layer consists of an input module at the input end and a peer output module at the other end.
  • The input module at layer i processes the information received from layer i+1 and sends the processed information to layer i−1.
  • The peer output module at layer i works in the opposite direction: it processes information received from layer i−1 and sends it to layer i.

Q5. Define the digital communication channel.

The communication channel is the part of the communication system between the source and the destination that is given and not under the control of the designer.

To a source-code designer, the channel may be viewed as a digital channel with binary input and output.

Q6. What is meant by the AWGN channel model?

AWGN stands for Additive White Gaussian Noise.

An AWGN channel is a channel model in which an independent white Gaussian noise waveform is added to the input signal:

Y(t) = X(t) + Z(t)

where:

  • X(t) = input signal,
  • Z(t) = additive white Gaussian noise,
  • Y(t) = output signal.

"Additive" means the noise is added to the signal; "white" means its power spectral density is constant over frequency; "Gaussian" means its amplitude has a Gaussian distribution.

Q7. Explain what is meant by the linear Gaussian channel model.

In a linear Gaussian channel, the input waveform X(t) is first passed through a linear filter with impulse response h(t), and then independent white Gaussian noise Z(t) is added:

Y(t) = X(t) * h(t) + Z(t)

where * denotes convolution.

  • X(t) = input waveform,
  • h(t) = impulse response of the linear filter,
  • Z(t) = independent white Gaussian noise,
  • Y(t) = output waveform.

This model is good for wireline communication and line-of-sight wireless communication. It is a poor model for non-line-of-sight mobile communication.

Q8. Define line coding.

Line coding is the process of choosing a code for use within a communication system for transmitting a digital signal down a transmission line. It represents the digital data (binary 1s and 0s) by specific voltage or current waveform patterns for transmission over a communication link.

The waveform pattern used to represent the 1s and 0s is called line encoding. Line codes are commonly used in computer communication networks over short distances.

SHEET 2 — Chapter 2: Digital Modulation

Q1. Explain what is meant by digital modulation.

Digital modulation is the process of modulating a digital information signal onto an analog carrier signal for transmission.

The carrier is usually a sinusoid:

v(t) = V sin(2π f t + θ)

The digital data changes one or more of the carrier's amplitude V, frequency f, or phase θ, so that the receiver can recover the bits.

Q2. What is meant by passband transmission, and what are the main signaling schemes used in it?

Passband transmission is the process in which the incoming data stream is modulated onto a carrier with a fixed frequency and then transmitted over a band-pass channel.

The three basic signaling schemes used in passband data transmission are:

  1. Amplitude Shift Keying (ASK)
  2. Frequency Shift Keying (FSK)
  3. Phase Shift Keying (PSK)

Q3. Define each of the following.

(a) M-ary encoding

M-ary is a term derived from the word binary. The letter M represents the number of possible conditions, levels, or combinations for a given number of binary variables.

The number of bits necessary to produce M conditions is:

N = log2 M

where N = number of bits per signaling element, and M = number of possible signal conditions.

Equivalently, M = 2^N.

Example: M = 4 → N = 2 bits per symbol.

(b) Baud

Baud is the rate of change of a signal on the transmission medium after encoding and modulation have occurred. It is also called the modulation rate or symbol rate.

Baud = 1 / Ts

where Ts is the time duration of one signaling element in seconds.

For M-ary signaling:

Baud = fb / N

where fb is the bit rate and N = log2 M is the number of bits per symbol.

(c) Signal constellation diagram

A constellation diagram is a representation of a digitally modulated signal as a two-dimensional X–Y scatter diagram in the complex plane, at the symbol sampling instants.

Each point in the constellation represents one possible symbol. The horizontal and vertical axes usually represent the in-phase (I) and quadrature (Q) components.

(d) Bandwidth efficiency

Bandwidth efficiency is the ratio of the information bit rate to the transmission bandwidth. It indicates how efficiently the available bandwidth is used.

η = fb / B     (bits/s/Hz)

where fb = information bit rate in bits/s and B = transmission bandwidth in Hz.

Q4. Briefly explain the main principle of ASK, obtaining its waveform and probability of error.

Principle

Amplitude Shift Keying (ASK) is the simplest digital modulation technique. A binary information signal directly modulates the amplitude of an analog carrier.

There are only two possible output amplitudes:

  • Binary 1: the carrier is transmitted.
  • Binary 0: no carrier is transmitted.

ASK is similar to standard amplitude modulation, except that there are only two output amplitudes. It is sometimes called Digital Amplitude Modulation (DAM).

Mathematical expression

V_ASK(t) = {1 + Vm(t)} [A/2 cos(ωc t)]
  • Vm(t) = +1 V for logic 1, −1 V for logic 0.
  • A/2 = unmodulated carrier amplitude.
  • ωc = 2πfc.

For logic 1: V_ASK = A cos(ωc t). For logic 0: V_ASK = 0.

Hence the carrier is either ON or OFF, so ASK is also called On–Off Keying (OOK).

Waveform

The top panel shows ASK: a carrier burst for each 1, and zero output for each 0.

Probability of error

For matched-filter detection:

Pe = ½ erfc( √(Eb / 4N0) )

where Eb is the energy per bit and N0/2 is the two-sided power spectral density of the AWGN.

Components and operation

  1. Binary input source — produces the digital data (1s and 0s).
  2. Carrier oscillator — generates the sinusoidal carrier A cos(ωc t).
  3. Product modulator (balanced modulator) — multiplies the binary signal by the carrier. - When the input bit is 1, the carrier is passed to the output. - When the input bit is 0, the carrier is blocked, so the output is zero.
  4. Band-pass filter (BPF) / antenna — limits the transmitted spectrum and couples the signal to the channel.

The result is an OOK waveform: carrier bursts for 1s, silence for 0s.

Q6. Briefly explain the main principle of FSK, obtaining its waveform and probability of error.

Principle

Frequency Shift Keying (FSK) is a digital modulation technique in which the frequency of the carrier changes according to the binary input signal.

  • Binary 1 → mark frequency fm (high frequency).
  • Binary 0 → space frequency fs (low frequency).

The amplitude stays constant while the frequency shifts between mark and space.

Mathematical expression

V_FSK(t) = Vc cos[2π (fc + Vm(t) Δf) t]
  • Vc = peak carrier amplitude.
  • fc = center frequency.
  • Δf = peak frequency deviation.
  • Vm(t) = +1 for logic 1, −1 for logic 0.

For logic 1: f = fc + Δf (mark). For logic 0: f = fc − Δf (space).

Waveform

The middle panel of the waveform figure shows FSK: a high-frequency burst for 1 and a low-frequency burst for 0, with constant amplitude.

Probability of error

Noncoherent FSK:

Pe = ½ erfc( √(Eb / 2N0) )

Coherent FSK:

Pe = ½ erfc( √(Eb / N0) )

  1. Binary input — the digital data stream.
  2. Voltage-Controlled Oscillator (VCO) — generates a sinusoidal output whose frequency is controlled by the input voltage.

Δf = Vm(t) Kl

where Kl is the deviation sensitivity in Hz/V.

Q9. Briefly explain the main principle of PSK, obtaining its waveform and probability of error.

Principle

Phase Shift Keying (PSK) is a digital modulation technique in which the phase of the carrier signal changes according to the binary input signal, while the amplitude remains constant.

PSK is widely used for wireless LANs, biometrics, contactless operations, RFID, and Bluetooth communications.

The main types are:

  • Binary PSK (BPSK) — 2 phases.
  • Quadrature PSK (QPSK) — 4 phases.
  • Differential PSK (DPSK) — phase changes according to the previous value.

Waveform

For BPSK, the waveform is a sinusoid that switches phase by 180° whenever the input bit changes. The bottom panel of the waveform figure shows this.

Probability of error

For coherent BPSK:

Pe = ½ erfc( √(Eb / N0) )

This is the same expression as coherent FSK in this course.

Q10. Briefly explain the main principle of BPSK, obtaining its waveform.

Principle

Binary Phase Shift Keying (BPSK) is a digital modulation technique in which the carrier takes two possible phase angles: 0° and 180°.

  • Binary 1 → carrier with 0° phase: +sin(ωc t).
  • Binary 0 → carrier with 180° phase: −sin(ωc t).

BPSK is also called 2-phase PSK, Phase Reversal Keying, or bi-phase modulation. It is the simplest form of PSK, with N = 1 and M = 2. It is a form of square-wave modulation of a continuous wave (CW) signal.

Waveform

  • When the input is 1, the carrier is a positive sinusoid.
  • When the input is 0, the carrier is inverted (negative sinusoid).
  • When the input changes from 1 to 0 or 0 to 1, the output phase shifts by 180°.

The bottom panel of the waveform figure shows the BPSK waveform: the phase reverses at every change in the input bit.

Q12. By the aid of neat sketches, explain the main components of a QPSK transmitter and receiver, obtaining its truth table, phasor diagram, and constellation diagram.

Principle

Quadrature Phase Shift Keying (QPSK) is an M-ary encoding scheme with:

N = 2,   M = 4

It combines two bits together into groups called dibits, producing four possible input combinations:

00, 01, 10, 11

Each dibit generates one of four possible output phases:

+45°, +135°, −45°, −135°

Features of QPSK

  • QPSK is a variation of BPSK.
  • It is a DSB-SC (double-sideband suppressed-carrier) scheme.
  • It sends two bits at a time (one symbol = 2 bits).
  • It converts the bit stream into bit-pairs (dibits) instead of a single serial stream.
  • This halves the data bit rate in each channel, allowing space for other users.

The four possible QPSK phasors

The I and Q components add to give one of four phasors:

+sin(ωc t) + cos(ωc t)
+sin(ωc t) − cos(ωc t)
−sin(ωc t) + cos(ωc t)
−sin(ωc t) − cos(ωc t)

QPSK transmitter

  1. The bit splitter separates the input data into two streams: I (in-phase) and Q (quadrature).
  2. Each stream has a bit rate of fb/2.
  3. The I channel modulates the carrier (e.g., sin ωc t) in a balanced modulator.
  4. The Q channel modulates a 90°-shifted carrier (e.g., cos ωc t) in another balanced modulator.
  5. The two modulated outputs are added in a linear summer.
  6. The result is band-pass filtered to produce the QPSK output.

QPSK receiver

  1. The input passes through a BPF and a power splitter.
  2. Carrier recovery regenerates the reference carrier.
  3. A 90° phase shifter produces the quadrature carrier.
  4. Two product detectors multiply the received signal by the 0° and 90° carriers.
  5. Two LPFs extract the I and Q baseband signals.
  6. The decision circuit decides the two bits.
  7. Clock recovery and parallel-to-serial conversion reconstruct the original bit stream.

Receiver worked example (from the lecture)

Let the incoming QPSK signal be:

−sin(ωc t) + cos(ωc t)

This is the symbol with Q = 1, I = 0 (phase +135°).

I-channel product detector (multiply by sin ωc t):

I = (−sin ωc t + cos ωc t)(sin ωc t)
  = −sin² ωc t + (cos ωc t)(sin ωc t)
  = −½(1 − cos 2ωc t) + ½sin(2ωc t)
  = −½ + ½cos 2ωc t + ½sin 2ωc t

After the LPF removes the 2ωc t terms:

I = −½ V  →  logic 0

Q-channel product detector (multiply by cos ωc t):

Q = (−sin ωc t + cos ωc t)(cos ωc t)
  = −(sin ωc t)(cos ωc t) + cos² ωc t
  = −½sin(2ωc t) + ½(1 + cos 2ωc t)
  = ½ + ½cos 2ωc t − ½sin 2ωc t

After the LPF:

Q = +½ V  →  logic 1

So the recovered bits are Q = 1, I = 0, matching the transmitted symbol.

Bandwidth considerations (important)

The input data rate is fb. The bit splitter divides it into two channels:

Bit rate in I channel = fb / 2
Bit rate in Q channel = fb / 2

The highest fundamental frequency of the modulating waveform in each channel is:

fa = fb / 4

Each balanced modulator output is:

Output = (sin ωa t)(sin ωc t)
       = ½ cos[2π(fc − fb/4)t] − ½ cos[2π(fc + fb/4)t]

So the sidebands are at:

fc − fb/4    and    fc + fb/4

The minimum double-sided Nyquist bandwidth is:

fN = (fc + fb/4) − (fc − fb/4)
   = 2(fb/4)
   = fb/2

The carrier frequency cancels out, so the bandwidth does not depend on fc.

Baud and bandwidth summary

Baud = fb / N = fb / 2
fN = fb / 2

A. the mark and space frequencies are not generally continuous, so a local reference coherent with both is impractical
B. it requires too little bandwidth
C. it has no carrier
D. it is illegal

Answer: A — It is difficult to reproduce a local reference coherent with both mark and space.

Q76. BPSK uses two phases:

Answer: B — BPSK uses 0° and 180° (phase reversal keying).

Q77. The BPSK transmitter's balanced modulator acts as a:

A. phase-reversing switch
B. frequency mixer only
C. power amplifier
D. low-pass filter

Answer: A — It transfers the carrier in phase or 180° out of phase, depending on the logic input.

Q78. For a BPSK input of +sin(ωc t), the LPF output after coherent demodulation is:

Answer: A — sin² = 0.5 − 0.5cos2ωc t; the LPF removes the double-frequency term, leaving +0.5 V.

Q79. The minimum Nyquist bandwidth of BPSK is:

Answer: B — B = 2fa = 2(fb/2) = fb.

Q80. For BPSK, the baud rate compared with the bit rate is:

Q82. DPSK changes the phase according to:

Q83. For a BPSK modulator with fc = 70 MHz and fb = 10 Mbps, the upper side frequency is:

Q84. For the same BPSK system (fc = 70 MHz, fb = 10 Mbps), the minimum Nyquist bandwidth is:

A. 5 MHz
B. 10 MHz

Answer: B — B = 2fa = 2 × 5 = 10 MHz.

LECTURE 4 — Quadrature Phase Shift Keying (QPSK)

Q86. For QPSK, the values of N and M are:

A. N = 2, M = 4
B. N = 1, M = 2
C. N = 2, M = 2
D. N = 4, M = 2

Answer: A — QPSK is an M-ary scheme with N = log2 M = 2 and M = 4.

Q87. QPSK combines the input bits into groups called:

A. dibits
B. tribits
C. bytes
D. nibbles

Answer: A — Two bits form a dibit; each dibit maps to one of four phases.

Q88. The four possible QPSK output phases are:

A. 0°, 90°, 180°, 270°
B. +45°, +135°, −45°, −135°
C. 0° and 180° only
D. 0°, 120°, 240°

Answer: B — QPSK uses ±45° and ±135°.

Q89. QPSK is a variation of BPSK and is also a:

A. DSB-SC modulation scheme
B. single-sideband scheme
C. vestigial-sideband scheme
D. baseband scheme

Answer: A — The lecture states QPSK is a variation of BPSK and a DSB-SC scheme.

Q90. How many bits does one QPSK symbol carry?

A. 1
B. 2
C. 3
D. 4

Answer: B — N = log2 4 = 2 bits per symbol.

Q91. In the QPSK transmitter, the bit splitter:

A. inputs bits serially and outputs them in parallel to the I and Q channels
B. converts parallel bits to serial
C. adds noise
D. changes the carrier frequency

Answer: A — Two bits are clocked in serially and then output simultaneously in parallel.

Q92. In QPSK, the bit rate in each of the I and Q channels is:

A. fb
B. fb/2
C. fb/4
D. 2fb

Answer: B — The input data rate is divided between the two channels, so each carries fb/2.

Q93. The highest fundamental frequency of the modulating waveform in each QPSK channel is:

A. fb
B. fb/2
C. fb/4
D. 2fb

Answer: C — The lecture uses fa = fb/4 for each channel.

Q94. The sidebands at the output of a QPSK balanced modulator are at:

A. fc ± fb
B. fc ± fb/2
C. fc ± fb/4
D. fc ± 2fb

Answer: C — The product-to-sum expansion gives sidebands at fc ± fb/4.

Q95. The minimum double-sided Nyquist bandwidth of QPSK is:

A. fb
B. fb/2
C. fb/4
D. 2fb

Answer: B — fN = (fc + fb/4) − (fc − fb/4) = fb/2.

Q96. For QPSK, the baud rate is:

A. fb
B. fb/2
C. fb/4
D. 2fb

Answer: B — Baud = fb/N = fb/2 because each symbol carries 2 bits.

Q97. Using the lecture's Q I truth-table order, the dibit Q = 1, I = 0 produces the phase:

Q98. Using the lecture's Q I truth-table order, the dibit Q = 0, I = 1 produces the phase:

Q99. The four possible QPSK phasors are:

A. ±sin ωc t ± cos ωc t
B. ±sin ωc t only
C. ±cos ωc t only
D. sin ωc t and cos ωc t only

Answer: A — The I and Q components combine as ±sin ωc t ± cos ωc t, giving four phasors.

Q100. In the QPSK transmitter, the I and Q modulated outputs are combined by:

A. a linear summer
B. an envelope detector
C. a comparator
D. a VCO

Answer: A — The two balanced-modulator outputs are added in a linear summer.

Q101. In the QPSK receiver, the recovered carrier must be:

A. frequency and phase coherent with the transmit reference

D. unmodulated at 0 Hz

Answer: A — Coherent detection requires the local carrier to match the transmit reference in frequency and phase.

Q102. The outputs of the QPSK product detectors are fed to the:

B. VCO

Answer: A — The bit combining circuit converts the parallel I and Q data into a single binary output stream.
